# AI 个人助手 - 技术设计文档

> 创建日期: 2026-05-21

## 1. 项目概述

使用 Go 语言开发一个 AI 个人助手，第一版目标为实现**文件编辑助手**功能，类似 Claude Code、Codex 等工具的核心交互模式。

### 1.1 第一版核心功能

- 用户通过命令行与 AI 助手交互
- AI 助手可以读取、编辑、创建文件
- 支持通过 OpenAI 兼容 API 接入任意大模型
- 用户可自定义模型地址（base URL）和 API Key

## 2. 技术选型

| 类别 | 选择 | 说明 |
|------|------|------|
| 语言 | Go 1.21+ | 简洁、高效、编译型 |
| AI SDK | `github.com/openai/openai-go` | OpenAI 官方 Go SDK，兼容 OpenAI API 格式 |
| 框架 | 无（或少量） | 第一版尽量使用标准库，减少依赖 |

## 3. 架构设计

### 3.1 整体架构

```
┌─────────────────────────────────────────┐
│              CLI (终端交互)              │
├─────────────────────────────────────────┤
│           Chat Loop (对话循环)           │
├──────────────┬──────────────┬───────────┤
│  LLM Client │ File Tool    │  Config   │
│  (OpenAI)   │ (文件操作)   │ (配置管理) │
└──────────────┴──────────────┴───────────┘
```

### 3.2 核心模块

#### 3.2.1 配置管理 (config)

- 存储模型配置（base URL、API Key、模型名称）
- 支持配置文件（如 `~/.ai-assistant/config.yaml`）或环境变量
- 配置项：
  - `OPENAI_BASE_URL`: OpenAI 兼容 API 地址
  - `OPENAI_API_KEY`: API Key
  - `MODEL`: 模型名称（如 `gpt-4`, `claude-sonnet-4-20250514` 等）

#### 3.2.2 LLM 客户端 (llm)

- 基于 `openai-go` SDK
- 封装聊天补全（chat completion）调用
- 支持流式输出（streaming）
- 支持 tool calling（工具调用）

#### 3.2.3 文件工具 (tools/file)

第一版支持的文件操作：

| 工具名 | 功能 |
|--------|------|
| `read_file` | 读取文件内容 |
| `write_file` | 写入/创建文件 |
| `edit_file` | 编辑文件（替换指定内容） |
| `list_files` | 列出目录下的文件 |

#### 3.2.4 对话循环 (chat)

- 维护对话历史（messages 列表）
- 处理用户输入
- 调用 LLM 并处理响应
- 处理 tool call 请求，执行工具后将结果返回给 LLM
- 流式输出 AI 回复

#### 3.2.5 CLI 入口 (cmd)

- 解析命令行参数
- 初始化配置
- 启动对话循环

## 4. 数据流

```
用户输入 → Chat Loop → LLM Client → [LLM API]
                                      ↓
                              LLM 返回 (文本 or tool call)
                                      ↓
                          如果是 tool call → File Tool → 执行 → 结果返回 LLM
                          如果是文本     → 流式输出到终端
```

## 6. OpenAI 兼容 API 接入

`openai-go` SDK 支持自定义 base URL，因此可以接入任何兼容 OpenAI API 格式的服务：

```go
client := openai.NewClient(
    openai.WithAPIKey(apiKey),
    openai.WithBaseURL(baseURL),
)
```
