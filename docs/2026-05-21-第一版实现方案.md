# AI 文件编辑助手 - 第一版实现方案

> 日期: 2026-05-21

## 目标

用 Go 实现一个终端 AI 助手，可以读取和编辑文件，通过 OpenAI 兼容 API 调用大模型。使用 Go 标准库 `log/slog` 输出结构化日志。

## 项目结构

```
Makefile             # 构建和运行
go.mod
cmd/main.go          # 入口
internal/config.go   # 配置读取
internal/llm.go      # openai-go 封装: streaming + tool call
internal/tools.go    # 文件操作工具
```

## Makefile

```makefile
.PHONY: run build deps

deps:
	go mod tidy

	go build -o bin/ai-assistant ./cmd/

	go run ./cmd/

debug:
	AI_LOG_LEVEL=debug go run ./cmd/
```

## Tool 定义

- `read_file(path)` → 返回文件内容
- `write_file(path, content)` → 写入文件
- `edit_file(path, old_string, new_string)` → 替换文件内容

## 日志设计

使用 Go 1.21 标准库 `log/slog`，输出结构化 JSON 日志到 stderr，终端交互信息输出到 stdout。

### slog 配置

```go
// cmd/main.go 中初始化
logger := slog.New(slog.NewTextHandler(os.Stderr, &slog.HandlerOptions{
    Level: slog.LevelInfo, // 可通过环境变量设为 DEBUG
}))
slog.SetDefault(logger)
```

### 日志级别

| 级别 | 用途 | 示例 |
|------|------|------|
| `DEBUG` | API 请求/响应详情 | `slog.Debug("API request", "model", model, "messages", len(msgs))` |
| `INFO` | 工具调用、操作结果 | `slog.Info("tool called", "tool", "read_file", "path", "main.go")` |
| `WARN` | 非致命问题 | `slog.Warn("file not found", "path", p)` |
| `ERROR` | 错误 | `slog.Error("API call failed", "err", err)` |

### 日志输出示例 (stderr)

```
time=2026-05-21T10:00:00Z level=INFO msg="tool called" tool=read_file path=main.go
time=2026-05-21T10:00:00Z level=INFO msg="tool result" tool=read_file lines=120
time=2026-05-21T10:00:01Z level=INFO msg="tool called" tool=edit_file path=main.go
time=2026-05-21T10:00:01Z level=INFO msg="tool result" tool=edit_file success=true
```

## 核心流程

```
1. 初始化: 读取配置 → 创建 openai client → 初始化 slog
2. 打印提示语，进入循环:
   a. 读取用户输入 (stdout)
   b. 追加到 messages 列表
   c. 调用 LLM (streaming)
      - slog.Info("calling LLM")
      - 流式输出文本到 stdout
   d. 如果 LLM 返回 tool call:
      - slog.Info("tool called", ...) 打印调用信息
      - 执行工具
      - slog.Info("tool result", ...) 打印执行结果
      - 将结果追加到 messages
      - 回到 2c，直到无 tool call
3. 回到 2a
```

### LLM 调用 + tool call 循环

```go
func (c *LLMClient) Chat(ctx context.Context, messages []openai.ChatCompletionMessageParamUnion) error {
    for {
        slog.Info("calling LLM", "model", c.model)

        stream := c.client.Chat.Completions.NewStreaming(ctx, openai.ChatCompletionNewParams{
            Model:    openai.F(c.model),
            Messages: openai.F(messages),
            Tools:    openai.F(c.tools),
        })

        var toolCalls []openai.ChatCompletionMessageToolCall
        var textBuf strings.Builder

        for stream.Next() {
            chunk := stream.Current()
            delta := chunk.Choices[0].Delta
            textBuf.WriteString(delta.Content)
            // 收集 tool_calls
            for _, tc := range delta.ToolCalls {
                // 累积 tool call 数据
            }
            // 实时输出到 stdout
            fmt.Print(delta.Content)
        }

        if len(toolCalls) == 0 {
            fmt.Println()
            return nil
        }

        // 执行 tool call
        for _, tc := range toolCalls {
            slog.Info("tool called", "tool", tc.Function.Name, "args", tc.Function.Arguments)
            result := executeTool(tc.Function.Name, tc.Function.Arguments)
            slog.Info("tool result", "tool", tc.Function.Name, "success", result.Success)
            messages = append(messages, openai.ToolMessage(tc.ID, result.Raw))
        }
    }
}
```

### 工具函数日志示例

```go
func readFile(path string) ToolResult {
    slog.Debug("reading file", "path", path)
    content, err := os.ReadFile(path)
    if err != nil {
        slog.Warn("file read failed", "path", path, "err", err)
        return ToolResult{Success: false, Raw: err.Error()}
    }
    slog.Info("file read success", "path", path, "lines", strings.Count(string(content), "\n")+1)
    return ToolResult{Success: true, Raw: string(content)}
}
```
