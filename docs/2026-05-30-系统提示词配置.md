# 支持系统提示词配置

> 日期: 2026-05-30

## 目标

让 AI 文件编辑助手支持通过环境变量配置系统提示词，无需修改源代码。

## 当前问题

目前的 `cmd/main.go` 中，`messages` 列表是空的，没有任何系统提示词。用户需要手动修改源码添加 system message 才能使用系统提示词。

## 方案设计

### 1. 配置层 (`internal/config.go`)

在 `Config` 结构体中新增 `SystemPrompt` 字段，从环境变量 `AI_SYSTEM_PROMPT` 读取。

```go
type Config struct {
    BaseURL      string
    APIKey       string
    Model        string
    LogLevel     slog.Level
    SystemPrompt string  // 新增
}
```

```
# .env 或环境变量
AI_SYSTEM_PROMPT=你是一个专业的 Go 文件编辑助手...
```

### 2. 启动层 (`cmd/main.go`)

在对话循环开始前，如果配置了系统提示词，将其作为第一条 message 添加到 `messages` 列表中。

```go
// 在 for 循环之前
var messages []openai.ChatCompletionMessageParamUnion

if cfg.SystemPrompt != "" {
    messages = append(messages, openai.SystemMessage(cfg.SystemPrompt))
}
```

### 3. 流式输出和工具调用

这两个功能已经存在于 `internal/llm.go` 的 `Chat` 方法中，不需要修改。系统提示词只是 messages 列表中的第一条消息，后续的 streaming + tool call 循环完全不受影响。

## 修改的文件

| 文件 | 变更 |
|------|------|
| `internal/config.go` | `Config` 结构体新增 `SystemPrompt` 字段，`LoadConfig` 从 `AI_SYSTEM_PROMPT` 读取 |
| `cmd/main.go` | 启动时如果配置了 `SystemPrompt`，将其作为第一条 system message 添加到 messages |
| `.env.example` | 添加 `AI_SYSTEM_PROMPT` 示例配置 |

## 使用方式

```bash
# 方式1: 通过 .env 文件
AI_SYSTEM_PROMPT="你是一个专业的Go助手"

# 方式2: 通过环境变量
AI_SYSTEM_PROMPT="你是一个专业的Go助手" make run
```
