# 修复工具调用参数顺序错误

> 日期: 2026-05-30

## 问题

调用工具时出现 400 Bad Request 错误：
```
"An assistant message with 'tool_calls' must be followed by tool messages responding to each 'tool_call_id'"
```

## 根因

`openai.ToolMessage(content, toolCallID)` 的参数顺序是 **content 在前，toolCallID 在后**。

代码中写反了：
```go
// 错误
messages = append(messages, openai.ToolMessage(tc.ID, result.Raw))
```

这导致 tool 响应消息的 `tool_call_id` 字段被设置为工具结果文本，而 `content` 被设置为 tool call ID。API 无法匹配 tool_call_id，返回 400 错误。

## 修复

```go
// 正确
messages = append(messages, openai.ToolMessage(result.Raw, tc.ID))
```

## 同时修复

- 日志中增加 `tool_call_id` 字段，方便排查工具调用问题
